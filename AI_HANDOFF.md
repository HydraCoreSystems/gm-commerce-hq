# AI Handoff Standard

Use this format whenever work moves between Claude, ChatGPT, GitHub Copilot, or another contributor.

## Task

- Issue:
- Objective:
- Repository:
- Branch:

## Work Completed

Describe what was actually changed. Include files, commits, pull requests, migrations, or external configuration.

## Verification

Describe tests run and results observed. Clearly identify anything not tested.

## Decisions Made

List decisions that affect future implementation. Add durable decisions to `DECISIONS.md`.

## Remaining Work

List only concrete unfinished work required by the issue's acceptance criteria.

## Blockers or Risks

State missing credentials, unresolved owner decisions, provider limits, failing tests, or uncertain assumptions.

## Recommended Next Action

Give the next contributor one clear starting action.

---

A conversation summary alone is not a sufficient handoff. The relevant code, issue state, and documentation must be preserved in GitHub.
