# GM Commerce Headquarters

This repository is the project-management headquarters and permanent source of truth for GM Commerce.

GM Commerce exists to help Gathering Moss get products online faster, prevent inventory mistakes, and operate with minimal human intervention while keeping Phil and Crystal in control of important business decisions.

## Start Here

1. Read [PROJECT_MANAGER.md](PROJECT_MANAGER.md).
2. Review [VISION.md](VISION.md) and [ROADMAP.md](ROADMAP.md).
3. Check [STATUS.md](STATUS.md) for the current milestone, active work, and next task.
4. Use GitHub Issues for executable work. Work belongs to GM Commerce; Claude, ChatGPT, Copilot, or Phil may be assigned as the contributor.

## Connected Repositories and Components

- `HydraCoreSystems/skrybix-webapp` — existing plant inventory and plant-ID system.
- Product SKU Generator — local non-plant SKU and photo-folder utility; repository location still to be recorded.
- Future GM Commerce application repository — not yet created.

## Version 1 Principle

A feature belongs in Version 1 only when it helps Gathering Moss increase sales, reduce repetitive work, reduce costly mistakes, or creates a required foundation for those outcomes without delaying useful delivery.

Advanced analytics, autonomous marketing, financial forecasting, HydraCore, and HydraCloud are outside the current Version 1 scope.
